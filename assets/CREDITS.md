# Kredit aset

Gambar diambil dari wiki penggemar hanya sebagai bahan video tips, tanpa perubahan, dan tidak dilisensikan ulang oleh repo ini.

Semua file berasal dari **Mobile Legends: Bang Bang Wiki di Fandom** (https://mobile-legends.fandom.com), diunduh pada 2026-10-14 lewat MediaWiki API. Tidak ada file dari Liquipedia atau MLBB Hub yang dipakai (keduanya hanya dicek: ikon hero di sana juga 128x128, ikon item MLBB Hub lebih kecil dari versi Fandom).
